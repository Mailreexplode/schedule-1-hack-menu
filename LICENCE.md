## 🧩 About

**Schedule I overlay** is a curated list of Schedule I open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, startpos switcher
- **Quality-of-Life Helpers** — item catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Startpos Switcher — practice from any checkpoint
- Show Hitboxes — visualize obstacle hitboxes
- Replay Notes — record and review level runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Icon Catalog — browse icons, colors, trails, death effects
- Custom Skin Notes — organize player cosmetics
- Solid Wave Trail — improved wave visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-level
- Jump Buffer Notes — chain complex maneuvers in the editor

### 🛠️ Additional Tools
- overlay Overlay Notes — visual cues for study
- Resource Tracker — keep track of in-game items
- Map overlay — understand level layouts
- Loot Helper — organize found items
- HUD Customization — adjust on-screen info

## 🛠️ Troubleshooting

- **Overlay does not appear:** Ensure the game is running in windowed or borderless mode.
- **Hotkeys not working:** Run the helper as administrator.
- **Game crashes on launch:** Verify game files and disable other overlays.
- **Antivirus flags the file:** Add an exclusion; false positives are common.
- **Performance issues:** Lower overlay opacity or disable advanced features.
